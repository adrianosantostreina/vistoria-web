# Prompts do livro

Os prompts que aparecem nos capítulos 14 e 15 de *Desenvolvimento Acelerado
com IA*, prontos para copiar e adaptar ao seu projeto.

| Arquivo | Capítulo | Quando usar |
|---|---|---|
| `14-bootstrap.md` | 14 | Uma vez, no início do projeto: monta a fundação do harness |
| `15-promocao-a-comando.md` | 15 | Você digitou a mesma instrução pela quarta vez |
| `15-extracao-de-skill.md` | 15 | Você explicou o mesmo procedimento pela terceira vez |
| `15-incidente-vira-regra.md` | 15 | Quebrou algo e não havia proibição escrita |
| `15-isolamento-em-subagente.md` | 15 | Uma tarefa está entupindo a sessão principal |
| `15-poda.md` | 15 | A cada dois ou três meses, para cortar o que não tem mais uso |
| `15-diagnostico.md` | 15 | O agente piorou e ninguém sabe por quê |

Os arquivos do harness que o prompt de bootstrap produziu neste repositório
estão em `CLAUDE.md`, `.claude/rules/RULES.md`, `.claude/settings.json`,
`docs/spec/CONSTITUTION.md` e `docs/DECISIONS.md`.
